Project

What

An indie game development project developed in collaboration by Ben, Nicholas, Tim, and Ed Muhlestein.

Roles

Nick Muhlestein:

  • Development Oversight: Directing production milestones, task prioritization, and team coordination.
  • Project Coordinator: Streamlining team workflows and tracking feature completion.
  • Scrum Master / Agile Lead: Managing sprint cycles, daily standups, and project delivery schedules.

Tim Muhlestein:

  • Game Design & Mechanics: Conceptualizing core gameplay mechanics, level design, and creative direction.
  • Game Design & Development: Driving game concepts, mechanics design, and core gameplay programming.
  • Game Concept & Execution: Translating game ideas into playable prototypes and finished mechanics.

Ed Muhlestein:

  • Project Infrastructure: Set up the agile project management framework and team workflow processes.
  • Web Architecture: Design and build the full-stack website architecture to support project tracking.
  • Deployment & Launcher: Develop a custom application launcher for automated game delivery and deployment.

Ben Muhlestein:

  • Game Design & Concept Development: Conceptualizing core gameplay ideas, narrative themes, and initial mechanics.
  • Lead Game Designer: Authoring core game concepts, world design, and gameplay rules.
  • Creative Concept Developer: Turning high-level gameplay ideas into playable design specifications.
